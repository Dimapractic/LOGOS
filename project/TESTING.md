# Проверка LOGOS 1.1

10 сквозных HTTP-тестов пройдены в Linux за 38,512 с. Протокол: `../tests/test-results.txt`. Тесты используют отдельные временные базы и проверяют интеграцию, повторы, идемпотентность и обработку ошибок.

Проверка в Chromium: создание заказа, просмотр карточки, навигация, повтор после двух отказов TMS, мобильный экран 390 px и локальный Swagger. Ошибок JavaScript, внешних запросов и горизонтального переполнения не обнаружено. Результат: `../tests/ui-results.json`.

Запуск тестов без интернета в Windows: `../TEST_OFFLINE.bat`. Windows-сборка содержит Python 3.12.10 x64 и 18 зависимостей; совместимость метаданных зависимостей проверена. Исполнение на Windows ещё не проверялось: выполните контрольный запуск на ноутбуке перед защитой.

Из собственного Python с установленными зависимостями: `python -m unittest discover -s tests -v`.
